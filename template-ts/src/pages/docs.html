Getting Started with K.I.S.S (TypeScript)

Everything you need to know to build beautiful landing pages with the K.I.S.S TypeScript starter template.

Quick Start

Create a new project using the CLI and select TypeScript:

npx @misterzik/create-kiss my-project
# Choose option 2 for TypeScript
cd my-project
npm install
npm run start

Project Structure

Your scaffolded TypeScript project contains:

my-project/
├── src/
│   ├── index.html          # Main landing page
│   ├── pages/              # Additional pages
│   │   └── docs.html       # This documentation page
│   ├── js/
│   │   └── app.ts          # TypeScript entry point
│   ├── scss/
│   │   └── app.scss        # Sass entry point
│   └── assets/
│       └── images/         # Image assets
├── tsconfig.json           # TypeScript configuration
├── webpack.config.js       # Webpack configuration
└── package.json            # Dependencies and scripts

Available Scripts

  • npm run start
    Starts the development server with hot reload at http://localhost:9000
  • npm run build
    Builds optimized production assets to the dist/ folder

Template Features

  • TypeScript 5 – Type-safe JavaScript with strict mode
  • Webpack 5 – Modern bundling with hot reload
  • Sass/SCSS – Powerful CSS preprocessing
  • Babel – ES6+ JavaScript transpilation
  • ts-loader – TypeScript compilation for Webpack
  • Animate.css – Ready-to-use CSS animations
  • Multi-page support – Add pages in src/pages/
  • Asset pipeline – Automatic image and font optimization

TypeScript Configuration

The template includes a tsconfig.json with recommended settings:

  • Strict mode enabled – Catch errors early
  • ES2015 target – Modern JavaScript output
  • ESNext modules – Tree-shaking support
  • Source maps – Debug TypeScript in browser

Customize tsconfig.json to fit your project needs.

Writing TypeScript

The main TypeScript file is src/js/app.ts. Example: 

const select = (selector: string): HTMLElement | null => {
  return document.querySelector(selector);
};

const updateYear = (): void => {
  const yearElement = select('#year');
  if (yearElement) {
    yearElement.textContent = new Date().getFullYear().toString();
  }
};

TypeScript provides autocomplete, type checking, and better IDE support for safer code.

Customization

All source files are in the src/ directory and are yours to customize:

  • HTML – Edit src/index.html and files in src/pages/
  • Styles – Modify src/scss/app.scss and create partials
  • TypeScript – Add functionality in src/js/app.ts
  • Assets – Place images in src/assets/images/

Adding New Pages

Create a new HTML file in src/pages/ and Webpack will automatically generate it:

  1. Create src/pages/about.html
  2. Restart the dev server
  3. Access at http://localhost:9000/about.html

Type Definitions

Install type definitions for third-party libraries: 

npm install --save-dev @types/library-name

This enables TypeScript autocomplete and type checking for external packages.

Deployment

Build your project for production:

npm run build

TypeScript is compiled to JavaScript during the build. Deploy the dist/ folder to any static hosting service:

  • Netlify
  • Vercel
  • GitHub Pages
  • AWS S3
  • Any CDN or web server
